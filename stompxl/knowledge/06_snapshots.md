# Snapshot design (4 per preset, one per song section)

- Each snapshot maps to a song section or playing role, e.g. INTRO / VERSE / CHORUS / SOLO. Order them as they first occur in the song: the player steps forward with SNAP up (FS1) and back with SNAP down (FS4). Name them by section (max 10 characters).
- Snapshots should make the song playable by snapshot changes alone, and they do it by switching blocks on and off. Every block keeps one set of values across all four snapshots, so the player can dial a block once by hand and have it hold in every section. Don't nudge a Mid, a Level or a Mix a little from snapshot to snapshot.
- Keep amp and cab on in every snapshot. Switch drives, modulation, delay and reverb on/off per section.
- Solos: lift the solo by switching on a drive (its Level set a little hot) and the delay, not by raising amp or block levels in the snapshot.
- Change a value in a snapshot only when a section can't work without it, e.g. a clean intro in a heavy song (Enter Sandman) that must drop the amp's Drive a long way, with drives off and more reverb/chorus switched on; raise Channel Volume with it so it stays level. Or when the player asks for it.
- If the song has fewer than 4 distinct sounds, use the spare snapshot for a useful variant made of different blocks on/off (e.g. a "LEAD+" with the delay and a second drive on, or an alternate rhythm).
