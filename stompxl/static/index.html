    How this works

    Your toggle choices are remembered. With the wah off, the expression pedal becomes a volume pedal. Every preset gets 4 snapshots, one per section of the song. Claude also says whether the song would benefit from the wah, expression pedal, looper, or Poly Capo. On a NAM rig, "Full-rig captures only" sticks to captures that include their cab, which saves the cab block's DSP. The box above the instructions shows how much DSP your rig and toggles leave and which other pedals still fit. The Stage boost is an off drive before the amp that Stage mode's Gain boost switches on.

    No AI: you get a preset with 4 snapshots (Intro, Verse, Chorus, Solo) and your usual noise gate. Build it with Edit values. The amp and cab apply to the headphones/FRFR rig; other rigs start empty. You can have Claude write a song plan later if you like.

    No AI, and nothing on the pedal changes. From the pedal: quit HX Edit first (only one program can use the USB connection). From a file: export a preset from HX Edit, or use one you downloaded. Blocks, values, snapshots, footswitches, expression pedal, gate and output come across; anything that doesn't is listed in the new version's notes.

              Add a gear note

              One-tap moves in a pedal's close-up (tap a block while editing). Changes are in the units the editor shows: Presence -1 nudges, LowCut = 100 sets, Decay x0.75 scales, and Gain|Drive means whichever the pedal has. "+ Save as pick" in a close-up makes one from what you just dialled in.

                Add a quick pick

                Settings

                Higher effort gives more careful tones but takes longer and costs more. Medium is a good default.

                NAM captures

                  Edit as text

                  For the two NAM rigs, one capture per line: IR slot (where the converted capture sits on the pedal, or - for one only on the computer) | name | what amp it is | "cab" if it includes its cabinet. NAM on pedal needs the NAM A2 Lite firmware, an unofficial third-party mod that is not from Line 6 and is used at your own risk, plus A2 Lite captures; see docs/nam.md.

                  A fine-grained token with Issues: read and write on this project's repository only.

                  Back up or move your library

                  Export

                  One file with every song and version, your guitars, sets, tone notes, quick picks, NAM captures and pedal backups. Your API keys and tokens are left out.

                  Export library

                  Import

                  Replaces the library here with one you exported. The library here is saved first, in the app's data folder, so you can bring it back. Keys and tokens here stay as they are.

                  Phones on this Wi-Fi

                  Use the app from a phone or tablet on the same home network. Each one is paired once with a code from this screen; nothing else on the network gets in. It's plain HTTP, so only turn it on at home, on a network you trust. Sending to the pedal still goes through this computer's USB cable.

                      Send diagnostics

                      Gathers what just happened: what this page showed and sent, the last pedal failures with their USB traffic, and the app's log, for a problem report on the app's GitHub page. Keys, emails, your home folder's name and the pedal's serial number are blanked out first. GitHub issues on a public project are public, so read it before you send.

                      Sends failing? writes the preset in your send slot back to itself, unsaved, to see which part the pedal refuses. It adds the result to the note.
