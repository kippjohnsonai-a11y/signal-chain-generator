# HX Stomp XL: recommended Global Settings

Based on the HX Stomp XL Owner's Manual (Global Settings, pages 55-60), for this setup:

- Guitars: Fender Stratocaster (SSS) and Gibson Les Paul (HH), both with passive pickups.
- Presets: generated by this app, with 4 snapshots per song in the order the song is played. The looper is on FS6; drive, delay and boost go on FS5, FS2 and FS3.

Open the menu: press **PAGE ◀ and PAGE ▶ together**, then **Knob 2 (Global Settings)**. Turn the Upper Knob to pick a submenu, and press PAGE for more parameters.

## The footswitch layout this is built around

```
 top row:     FS1 SNAP ▲    FS2 stomp    FS3 stomp    MODE
 bottom row:  FS4 SNAP ▼    FS5 stomp    FS6 LOOPER   TAP/TUNER
```

This needs **Stomp Mode = 4 Switch** and **Up/Down Switches = Snapshots** (Footswitches menu below). Snapshots and stomps then work side by side, so you never have to switch modes mid-song. SNAP ▲ moves to the next section, SNAP ▼ goes back, and the four stomps stay live the whole time.

## Ins/Outs
| Setting | Set to | Why |
|---|---|---|
| Input Level | **Inst** | The manual's setting for passive pickups (both guitars). |
| Output Level | FRFR / headphones / PA / mixer: **Line**. Front of an amp: **Inst**. 4-cable, into the amp's effects return: **Line** for a line-level loop, **Inst** for an instrument-level loop. | Matches the level of whatever the pedal feeds. A mismatch causes noise or clipping. |
| Send/Return L, Send/Return R | **Inst** | Inst is for stompboxes or the 4-cable method's send to the amp's input. Line is only for rack gear. |
| Return Type | **Send/Return** | Keep the Returns as effects-loop inputs. Change to Aux In only if you want to jam along to a phone or MP3 player plugged into Return L/R. |
| USB In 1/2 Trim | **0.0 dB** | The manual says to leave it. This is the Mac's audio (YouTube, backing tracks) coming out of the Stomp's outputs. |
| Phones Monitor | **Main L/R** | You hear what the main outputs send. |
| Volume Controls | Into an amp (front or 4-cable): **Phones**. FRFR / headphones only: **Main+HP**. | With "Phones", the main outputs stay at unity gain, so the knob can't change how hard you hit the amp. |

## Preferences
| Setting | Set to | Why |
|---|---|---|
| Bypass Type | **DSP** | Delay and reverb tails fade naturally when you bypass everything. "Analog" is true bypass, but it cuts tails. |
| Snapshot Edits | **Discard** | Anything you stomp on during a song resets when you come back to that snapshot, so the song plays the same every time. (To save a change made live, press SAVE twice before leaving the snapshot.) |
| Tempo Pitch | **Transpr** (Transparent) | Delay repeats don't warble when the tempo changes. |
| EXP/FS Tip | **EXP 1** | Expression pedal input. |
| EXP/FS Ring | **Leave the default** with one pedal (your Moog). Two ordinary pedals on a Y cable: **EXP 2**. | Only one pedal is plugged in, on the jack's tip (EXP 1). |
| Tip / Ring Polarity | **Normal** | Change to Invert only if a pedal works backwards (e.g. volume loudest with the heel down). |
| Preset Number | **01A-32D** | Matches the labels the app shows. |
| Snapshot Reselect | **Reload** | Only applies in Snapshot footswitch mode, which this layout doesn't use. |
| Auto In-Z | **Enabled** | The input impedance follows the first block that is *on*, so a bypassed fuzz at the front doesn't dull your clean tone. |

## Footswitches
| Setting | Set to | Why |
|---|---|---|
| Stomp Select | **Press** | The default ("Touch") selects a block for editing when your foot just brushes a switch. "Press" only reacts to real presses. |
| Stomp Mode | **4 Switch** | FS1/FS4 become the Up/Down switches below; FS2, FS3, FS5, FS6 stay as stomps. |
| Preset Mode | **Moment** | After picking a preset with BANK, the pedal returns to your stomp/snapshot layout. |
| Snapsht Mode | **Moment** | Only matters if you enter full Snapshot mode (press ▲ and ▼ together). |
| Up/Down Switches | **Snapshots** | FS1 = next snapshot, FS4 = previous, instantly and with no bank queue. The app stores snapshots in the order you play the song. |
| Swap Up/Down | **Off** | Top = forward, bottom = back. Flip it if you'd rather step forward with the bottom switch. |
| TAP Function | **TAP/Tuner** | Tap for tempo; hold for the tuner. |
| FS7 / FS8 Function | Only with external footswitches | These are the rear EXP/FS jack's inputs, not MODE/TAP. |

Changing presets in this layout: press **▲ and ▼ together briefly** to reach Snapshot selection, or **hold both for 2 seconds** to cycle the Up/Down switches between Bank, Preset and Snapshot. For a gig, putting the set list in consecutive slots and using "Presets" works too.

## Your Moog expression pedal
- Plug it into the rear **EXP 1/2 | FS 7/8** jack with a normal TRS cable; no Y cable is needed for one pedal. It works as **EXP 1**.
- If it's a Moog EP-3, set its **polarity switch to "Other"** (the Moog setting is for Moog gear) and turn its **range knob to maximum** so the sweep covers the full travel. If the sweep is backwards or only works over part of the travel, flip that switch before touching the Stomp's Tip Polarity.
- The app is set to "One expression pedal" (Settings), so each preset has **one** block on the pedal, on EXP 1: a wah for wah songs, otherwise a Volume pedal for swells or a Pitch Wham for whammy parts. The wah is switched on with its footswitch.

## EXP Pedals
| Setting | Set to | Why |
|---|---|---|
| EXP 1 Position | **Global** | The manual's advice for wah and volume: the pedal keeps its physical position when you change presets, so nothing jumps. |
| EXP 2 Position | **Global** | Same reason. |

## MIDI/Tempo
| Setting | Set to | Why |
|---|---|---|
| MIDI Base Channel | **1** | Default. Only matters with MIDI gear. |
| MIDI Thru | **Off** | Nothing downstream to pass MIDI to. |
| Rx MIDI Clock | **Off** | Keeps each preset's stored song tempo. With a DAW running, a stray clock could override it. |
| Tx MIDI Clock | **Off** | Nothing to sync. |
| Tempo Select | **Per Preset** | The app stores each song's tempo in its preset, so delays sync without tapping. |
| USB MIDI | **On** | Harmless, and useful if you ever use a DAW or MIDI controller from the Mac. |
| MIDI PC Rx | **MIDI+USB** | Lets a MIDI controller or the Mac change presets later. |
| MIDI PC Tx | **Off** | The Stomp isn't controlling other gear. |

## Displays
| Setting | Set to | Why |
|---|---|---|
| LED Rings | **Dim/Brt** (default). **Off/Brt** on bright outdoor stages. | Shows at a glance which stomps are on. |
| Tap LED | **On** | A quick visual check that delays match the song's tempo. Turn it off if the blinking bothers you. |

## Input block noise gate (per preset, not in Global Settings)
- Every preset's **Input block** has a free noise gate (Gate, Threshold, Decay). The app turns it on and sets the threshold per song and guitar (Settings > Input noise gate: On / Claude decides / Off).
- "Send to pedal" sets the Input block's gate (on/off and threshold) for you; the push summary confirms it. Decay stays at whatever the slot had. To adjust by hand: Edit view → select the Input block → Knob 1 Gate, Knob 2 Threshold.

## Per-block option worth knowing (not in Global Settings)
- **Snapshot Bypass** (select a block, press ACTION, then PAGE, then Knob 3): set it to **Off** on a block you want to control only with its footswitch, e.g. the boost, so changing snapshots never turns it off. The app currently keeps the boost off in every snapshot instead.

## Don't
- Global Settings > ACTION > **Factory Settings** resets everything above (presets are untouched).
